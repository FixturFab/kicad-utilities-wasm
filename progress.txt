#### ERC JSON Output Format (kicad-cli v8.0.9)

Top-level structure:
```json
{
  "$schema": "https://schemas.kicad.org/erc.v1.json",
  "coordinate_units": "mm",
  "date": "ISO-8601 timestamp",
  "kicad_version": "8.0.9",
  "source": "filename.kicad_sch",
  "sheets": [
    {
      "path": "/",
      "uuid_path": "/root-uuid",
      "violations": [
        {
          "type": "pin_not_connected",
          "severity": "error|warning",
          "description": "Human-readable message",
          "items": [
            {
              "description": "Symbol U1 Pin 2 [-, Input, Line]",
              "pos": { "x": 1.3208, "y": 0.8636 },
              "uuid": "uuid-string"
            }
          ]
        }
      ]
    }
  ]
}
```

Note: positions in JSON appear to be in meters despite coordinate_units="mm" (KiCad v8.0.9 bug).
