## DRC/ERC JSON Configuration API — Implementation Progress

### Stage 1: DRC Design Settings Override
- Added kicad_configure_drc(const char* json_config) to api.cpp — parses design_settings JSON, applies all 17 fields to BOARD_DESIGN_SETTINGS with mm→IU conversion
- Added kicad_configure_drc declaration to include/kicad_drc_api.h
- Added _kicad_configure_drc to EXPORTED_FUNCTIONS in CMakeLists.txt
- Resets DRC engine after config changes to force re-init on next run
- Build verified: compiles and links successfully
- Created samples/drc-config-test.kicad_pcb with tracks at 0.1/0.15/0.2/0.25mm widths, vias at 0.4/0.5/0.6mm, clearance pairs at 0.1mm/0.15mm gaps, edge clearance at 0.1mm
- Removed s-expression comments (;; syntax not supported by KiCad parser)
- Verified PCB loads and DRC runs: default=26, strict=29, relaxed=16 violations
- Created test/test-drc-config.mjs: 28 assertions covering 8 test scenarios
  - Default DRC, relaxed config, strict config, 3 different violation counts
  - Error handling (no board, invalid JSON), partial config, empty config

### Stage 2: Netclass Configuration
- Added #include for netclass.h, project/net_settings.h, eda_pattern_match.h
- Added netclass parsing to kicad_configure_drc: creates/modifies netclasses with all 9 fields (clearance, track_width, via_diameter, via_drill, microvia_diameter, microvia_drill, diff_pair_width, diff_pair_gap, diff_pair_via_gap)
- Added netclass_assignments parsing: maps net names to netclass sets via SetNetclassLabelAssignment
- Added netclass_patterns parsing: maps wildcard patterns to netclasses via SetNetclassPatternAssignment
- Added SynchronizeNetsAndNetClasses(false) call after any netclass changes
- Build verified: compiles and links successfully with no errors
- Fixed SynchronizeNetsAndNetClasses: board has no m_project in WASM, so manually iterate nets and assign effective netclasses via net->SetNetClass(netSettings->GetEffectiveNetClass(...))
- Created samples/netclass-test.kicad_pcb: GND/VCC/SIG nets, 0.2mm tracks, two close pairs with 0.15mm edge-to-edge gaps
- Created test/test-netclass-config.mjs: 22 assertions covering 7 test scenarios
  - Baseline (relaxed Default → 0 clearance violations)
  - Power netclass high clearance → 1 violation (VCC-GND pair)
  - Power netclass low clearance → 0 violations
  - Both VCC+GND assigned to Power → 2 violations
  - Pattern-based assignment → 1 violation
  - Default netclass override → 2 violations
  - Violation count difference verification

### Stage 3: DRC Severity Configuration
- Added severity parsing to kicad_configure_drc: maps 35 human-readable names to DRCE_T enums, 3 severity strings to SEVERITY enum
- Build verified: compiles and links successfully (kicad_drc.mjs + kicad_drc.wasm)
- Created test/test-drc-severity.mjs: 34 assertions covering 7 test scenarios
  - Baseline DRC, ignore track_width → 6 fewer violations
  - Warning severity → same count but severity field changes to "warning" in JSON
  - Ignore multiple types → cumulative reduction
  - Combined severity + design_settings overrides
  - Ignore all violation types → 0 violations
  - Unknown severity names silently ignored
- Verified severity filtering in JSON output: "error"/"warning"/"ignore" correctly reflected

### Stage 6: Integration Tests and Edge Cases
- Stage 6a: Created test/test-manufacturer-rules.mjs: 38 assertions covering 7 test scenarios
  - JLCPCB (5mil track, 0.3mm drill): 22 violations
  - OSH Park (6mil track, 20mil via, 20mil edge): 29 violations (strictest)
  - PCBWay (4mil track, 0.15mm drill): 17 violations (most relaxed)
  - All three produce different violation counts on same PCB
  - Structural violations (dangling track/via) consistent across all configs
  - Manufacturer config + severity overrides combined test
  - Manufacturer config + netclass override combined test
- Stage 6b: Created test/test-config-persistence.mjs: 49 assertions covering 6 test scenarios
  - DRC design settings reset after PCB reload (baseline=26, strict=31, after reload=26)
  - DRC severity settings reset after PCB reload (ignored types removed then reappear)
  - DRC netclass settings reset after PCB reload
  - Loading a different PCB resets DRC config (switch between drc-config-test and netclass-test)
  - ERC severity settings reset after schematic reload (baseline=9, ignored=4, after reload=9)
  - Multiple configure calls then reload resets all accumulated overrides
