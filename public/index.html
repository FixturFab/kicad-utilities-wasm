KiCad WASM Tools

PCB and schematic validation in the browser, powered by WebAssembly

DRC Check

Run Design Rule Checks on PCB layouts. Detects clearance violations, unconnected nets, and more.

ERC Check

Run Electrical Rules Checks on schematics. Finds unconnected pins, power conflicts, and wiring errors.

Generate 3D STEP models from PCB layouts with interactive preview. Export for mechanical CAD integration.
